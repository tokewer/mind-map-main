# 本地持久化与复习视觉功能收尾设计

## 目标

完成本地版思维导图的磁盘持久化、图片落盘、删除同步、掌握度上色与复习节点发光闭环，并通过可重复的构建和 HTTP 测试证明关键行为。

## 当前根因

- 前端图片上传应调用 `POST /api/image`，后端却只匹配 `/api/image/<name>`；文件名实际位于 JSON 请求体。
- 后端原子写使用固定 `.tmp` 文件，多线程写同一路径时会冲突；存储写删失败仍返回成功。
- 同步层会把仍存在的键加入 `remove`；离线首次拉取失败后恢复时直接推送本地默认数据；工作区导入没有记录被覆盖删除的键。
- 掌握度上色调用 `node.setStyles()`，会把临时视觉状态写进节点数据并覆盖用户自定义样式；关闭时直接删除节点样式字段。
- 发光组件把 `<style>` 文本绑定到元素的 `style` 属性，动态规则无效；配置没有持久化 UI。

## 设计

### 后端接口

- `POST /api/image` 是规范上传端点，JSON 结构为 `{ "name": string, "data": data-url }`；兼容 `/api/image/`，拒绝带额外路径段的 POST。
- 图片名必须是普通文件名，扩展名必须在允许表内，data URL MIME 必须与扩展名兼容，base64 必须严格解码。
- 请求体上限为 25 MiB；超限返回 413。
- 所有文件写入使用目标目录内唯一临时文件，执行 `flush`、`fsync`、`os.replace`，失败时清理临时文件。
- 存储请求在进程级锁内执行写入和删除；先验证完整请求，再执行。任何 I/O 失败返回 500 和失败项，不能返回虚假成功。
- 对重复出现在 `keys` 与 `remove` 中的键，以写入为准，不执行删除。
- 写接口仅接受 `application/json`；浏览器带 `Origin` 时必须与当前回环服务同源，防止网页跨站修改本地数据。
- SVG 图片响应带 `sandbox` 和 `default-src 'none'` CSP，保留显示能力但禁止脚本执行。

### 前端同步

- `collectRemovalKeys` 只返回当前 localStorage 中不存在且本轮不写入的受管理键。
- 本地重新写入键时，保存前自动清除该键的 tombstone。
- 首次磁盘拉取失败设置待拉取状态；服务恢复后先拉取并只补齐本地缺失键，再推送本地状态。
- 工作区导入计算导入前后受管理键差集，对确实消失的键调用 `markKeyRemoved`，然后触发立即保存。
- 删除单个历史版本、复习浮窗配置变化都触发工作区/服务器自动保存。
- 服务器响应必须满足 `ok === true` 才更新磁盘快照和清除本轮已同步 tombstone。

### 掌握度上色

- 上色是临时展示状态，不修改导图节点数据，不进入撤销/重做，也不触发持久化。
- 给节点 SVG group 增加一个掌握度 class，并通过 CSS 自定义属性传入填充色和文字色。
- 关闭时只移除本功能添加的 class 和 CSS 变量，用户原有 `fillColor`、`color`、`borderColor` 保持不变。
- 监听节点树重新渲染、复习数据变化和颜色设置变化，开启时重新应用。

### 发光设置

- 配置存入现有 `SIMPLE_MIND_MAP_LOCAL_CONFIG.reviewGlow`，默认值为：启用、复习蓝 `#409eff`、重点金 `#f59e0b`、强度 12、速度 2 秒。
- 复习中心“设置与数据”提供启用开关、两种颜色、强度和速度控件；每次变更通过 Vuex `setLocalConfig` 持久化并发送 `review_glow_config_change`。
- `ReviewGlowSync` 从 Vuex 启动配置初始化；动态颜色通过 SVG group CSS 变量传入，关键帧使用静态 CSS 和变量，不再拼接 `<style>` 字符串。
- 配置值必须归一化：颜色为六位十六进制，强度 4-30，速度 0.5-6 秒。

## 数据一致性规则

- 正常启动时只从磁盘补齐 localStorage 缺失键，保留浏览器中较新的现存值。
- 工作区显式导入代表完整覆盖，导入后缺失的受管理键必须从磁盘删除。
- 服务离线期间 localStorage 继续工作；恢复后先完成待处理的首次拉取，再推送当前本地状态。
- 同一次请求中写入优先于删除，避免删除后快速重建同名键时丢失新值。

## 验证矩阵

- Python 单元测试：规范图片路由、非法路径、严格 base64、MIME/扩展名不匹配、存储写删冲突、非法键类型、原子写残留清理。
- HTTP 冒烟测试：启动临时端口与临时数据目录，执行图片 POST/GET、存储 POST/GET/remove，并检查实际文件。
- 前端检查：ESLint 与生产构建成功；构建产物包含 `/api/image` 而非 `/apiimage`。
- 手工视觉检查：掌握度开关不改节点数据且关闭后恢复原样；发光配置刷新后保留并立即影响节点。

## 范围限制

- 不新增依赖，不改为 Flask，不重构整个存储架构。
- 本轮不实现图片垃圾回收，也不改变 Docker/nginx 部署模式。
- 项目不是 Git 仓库，因此不执行或伪造提交步骤。
